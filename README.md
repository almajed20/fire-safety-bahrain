# نظام إدارة الحماية والسلامة من الحريق
## مملكة البحرين

---

## نظرة عامة

نظام شامل لإدارة السلامة من الحريق في مملكة البحرين، يتضمن ثلاثة مكونات رئيسية:

1. **الموقع الرئيسي للموظفين**: إدارة المنشآت والمخالفات
2. **تطبيق المفتش الميداني**: تسجيل المخالفات في الميدان
3. **لوحة تحكم ضابط العمليات**: عرض الخرائط الهندسية ومعلومات السلامة
4. **لوحة التحكم الذكية**: تحليلات وإحصائيات متقدمة (جديد!)

---

## الميزات الرئيسية

### 1. إدارة المنشآت
- تسجيل المنشآت الجديدة مع جميع التفاصيل
- رفع الخرائط الهندسية (DWG)
- تتبع متطلبات السلامة
- **جديد**: حقل المواد الخطرة (يوجد/لا يوجد)
- **جديد**: عدد الطوابق

### 2. إدارة المخالفات
- 26 نوع مخالفة مختلف
- نظام الموافقة/الرفض
- تتبع حالة الدفع
- رفع صور المخالفات
- سجل تاريخي كامل

### 3. لوحة العمليات
- البحث عن المنشآت
- عرض الخرائط الهندسية
- **جديد**: عرض عدد الطوابق
- **جديد**: عرض حالة المواد الخطرة
- معلومات أنظمة الإطفاء (Dry/Wet Riser)

### 4. لوحة التحكم الذكية (جديد!)
- **إحصائيات فورية**: إجمالي المنشآت، المخالفات، المباني الخطرة
- **تقييم الخطورة**: نظام ذكي لتقييم خطورة المباني
- **تحليل المخالفات**: رسوم بيانية لأكثر المخالفات تكراراً
- **تحليل شهري**: متابعة المخالفات على مدار العام
- **توقعات ذكية**: تحديد المباني المعرضة للخطر

## التقنيات المستخدمة

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Tailwind CSS
- **Charts**: Chart.js
- **Backend**: Python Flask
- **Storage**: LocalStorage (للنسخة الحالية)

---

## متطلبات التشغيل

### البرمجيات المطلوبة:
- Python 3.11 أو أحدث
- Flask
- متصفح حديث (Chrome, Firefox, Safari, Edge)

### التثبيت:

```bash
# 1. فك ضغط الملف
tar -xzf fire_safety_app_final_with_dashboard.tar.gz

# 2. الانتقال إلى مجلد المشروع
cd fire_safety_app

# 3. تشغيل الخادم
python3.11 main.py
```

### الوصول إلى النظام:
افتح المتصفح وانتقل إلى: `http://localhost:8080`

## نظام تقييم الخطورة

تستخدم لوحة التحكم الذكية نظام تقييم متقدم:

- **كل مخالفة**: +10 نقاط
- **وجود مواد خطرة**: +50 نقطة
- **عدم وجود Dry Riser**: +20 نقطة
- **عدم وجود Wet Riser**: +20 نقطة
- **أقل من مخرجين**: +30 نقطة

### مستويات الخطورة:
- **عالي جداً**: أكثر من 80 نقطة (أحمر)
- **عالي**: 50-80 نقطة (برتقالي)
- **متوسط**: أقل من 50 نقطة (أصفر)
